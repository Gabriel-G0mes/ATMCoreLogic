# ATMCoreLogic

Console-based ATM (Automated Teller Machine) system developed in Java, focusing on core programming logic and control flow.

## 🎯 Objective
Practice and demonstrate mastery of:
- Primitive data types
- Conditional structures (if / else)
- Repetition structures (do/while)
- Input validation
- Console-based user interaction

## 🛠 Technologies
- Java
- Scanner (java.util)
- Locale (java.util)

## 📋 Features
- View current balance
- Deposit funds with validation
- Withdraw funds with validation
- Menu-driven interface
- Safe exit control
- Handling of invalid user input

   ```bash
   git clone https://github.com/SEU_USUARIO/ATMCoreLogic.git
